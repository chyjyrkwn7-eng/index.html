## What changed

- **Filled glyphs** (`TAB_GLYPHS` in `setupBottomTabs`; `svg.tab-glyph`):
  - Home: a planet with a tilted ring - the near half of the ring crosses in front of the planet with a gap cut round it (an SVG mask, `tg-home-cut`), the far half goes behind.
  - Calendar: the reference's calendar - a rounded page, the header band solid, the body cut out (`fill-rule:evenodd`), twelve day dots (4 / 5 / 3 like the reference). No binder rings: the reference has none.
  - Leaderboard: a filled trophy (cup and base solid, handles stroked).
  - Profile stays the character. Settings is not on the bar.
- **Sizes**: one block after the build 327d icon rules ("THE REFERENCE BAR"), plain bar only (`.bottomtabs:not(.has-start-tab)`). The Start bar on the unit screen is untouched.
- **The platter's vertical inset is a CSS variable** (`--pill-in-y`, 5px default, 3.5px on the plain phone bar, 4.76px from 40rem), read by the lens JS (`pillInY()`, was the constant `PILL_IN_Y`). The bar's end padding moved with it (7.5px / 8.76px) so the platter stays concentric; the row's width calc moved with the padding so the bar is the same width as before.
- **Installing update** - the new build's first screen after an update. The old build (live 313c) shows its own "Pushing update…" for ~1.1s plus the fetch, sets `sessionStorage class26e.updating`, and reloads. This build's splash script reads (and consumes) that flag as before, and when it is set it puts up `#install-update` straight after the splash HTML: "INSTALLING UPDATE", the theme's glow, a bar filling over 10.5s, a line that slides in every ~1.17s (Installing the update, Initiating the sound system, Tuning the ambience, Refining colors, Polishing the Liquid Glass, Redrawing the road map, Teaching Nova new lines, Charging the planet system, Calibrating hundo effects, Almost there), "Your progress is saved." The splash runs exactly as long under it (`duration = INSTALL_MS`), so everything that already waits for a loading screen (What's New, Nova, tours, reward cards, the update check) waits for it; boot, recovery and sync run under it as on any launch. It fades out with the splash; a hard cap removes it at 12s whatever happens. **A tap does not skip it** (it is the ten seconds he asked to be seen). Reduce motion: no sheen, no slide; the bar still fills and the line still changes (information, as every loading bar here).
- This build's own "Pushing update…" (for updates from 327 on) gains a line under the bar: "Downloading the update…", "Packing up your progress…", "Getting the new build ready…". Its timing and the forced-update loop guard are unchanged.

## What a phone on 313c sees during the 313c -> 327 update

1. 313c's own screen: black, "Pushing update…", a sweeping bar, "Your progress is saved." (~1.1s plus the fetch).
2. The page reloads: a black frame (the html background), then from the first frames of the new page "INSTALLING UPDATE" with its bar filling and the lines changing, for 10.5s.
3. It fades into Home (or Welcome) - and then whatever 327 shows next (Nova's meeting / What's New for an account that has not met him).
